Climbing Stairs

leetcode.com/problems/climbing-stairs · Blind 75 · FAANG favourite

Problem Statement

You are climbing a staircase with n steps. Each time you can climb 1 or 2 steps. How many distinct ways can you reach the top?
Example 1
Input: n = 2
Output: 2
1+1 or 2.
Example 2
Input: n = 3
Output: 3
1+1+1, 1+2, 2+1.

Constraints

  • 1 ≤ n ≤ 45

Approaches Comparison

Approach 1 — Recursion (Fib) O(2n)

TimeO(2n)
SpaceO(n)

Exponential without memoization.

⚠ Interviewer will push back

This is a valid stepping-stone answer. But the problem requires better optimization. Always start by acknowledging this brute force/suboptimal time complexity before moving to the optimal solution.

Approach 2 — Fibonacci DP Optimal

TimeO(n)
SpaceO(1)

The number of ways to reach step n equals the number of ways to reach step n-1 (taking one step) plus ways to reach step n-2 (taking two steps). This is the Fibonacci sequence.

def climbStairs(n):
    a, b = 1, 1
    for _ in range(n - 1):
        a, b = b, a + b
    return b

Climbing Stairs IS Fibonacci

f(1)=1, f(2)=2, f(n)=f(n-1)+f(n-2). Reduce space to O(1) by only keeping the last two values.

Interview Playbook

  1. Recognize the pattern: Any problem where ways(n) = ways(n-1) + ways(n-2) is Fibonacci.
  2. Companies: Amazon, Google, Apple — a classic warm-up problem.
