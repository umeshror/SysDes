Longest Consecutive Sequence

leetcode.com/problems/longest-consecutive-sequence  ·  Blind 75 · FAANG favourite

Problem Statement

Given an unsorted array of integers nums, return the length of the longest consecutive elements sequence.

You must write an algorithm that runs in O(n) time.

Example 1
Input: nums = [100, 4, 200, 1, 3, 2]
Output: 4
The longest consecutive sequence is [1, 2, 3, 4]. Length = 4.
Example 2
Input: nums = [0, 3, 7, 2, 5, 8, 4, 6, 0, 1]
Output: 9
Sequence: [0,1,2,3,4,5,6,7,8], length = 9. Duplicate 0 is ignored.
Example 3 (Edge Case)
Input: nums = []
Output: 0
Empty array — return 0.

Constraints

  • 0 ≤ nums.length ≤ 10⁵
  • -10⁹ ≤ nums[i] ≤ 10⁹
  • Must solve in O(n) time

Approaches Comparison

Approach Time Space Notes
Brute Force (nested loop) O(n³) O(1) For each number, count its streak with nested loops. TLE on large input.
Sort + Walk O(n log n) O(1)–O(n) Sort, then scan. Clean but doesn't meet the O(n) requirement.
✅ Hash Set (Optimal) O(n) O(n) Only start counting from sequence start. Each number visited once.

Approach 1 — Brute Force O(n³)

TimeO(n³)
SpaceO(1)

For every element, check if n+1, n+2… exist by scanning the entire array. Three nested loops = cubic time. Fails with TLE for n = 10⁵.

def longestConsecutive(nums: list[int]) -> int:
    longest = 0
    for n in nums:
        current = n
        streak = 1
        while current + 1 in nums:   # O(n) scan each time
            current += 1
            streak += 1
        longest = max(longest, streak)
    return longest

Approach 2 — Sort then Walk O(n log n)

TimeO(n log n)
SpaceO(1)*

Sort the array first, then walk through it counting consecutive elements. Skip duplicates. Clear and easy to code, but doesn't meet the O(n) constraint.

Approach 3 — Hash Set (Optimal ✅) O(n)

TimeO(n)
SpaceO(n)
💡 The Key Insight

A number n is the start of a consecutive sequence if and only if n-1 does NOT exist in the set. Only start counting from sequence starts — so each number is visited at most twice (once for the set, once during count). Total = O(n).

Algorithm:

  1. Put all numbers into a set (O(n), O(1) lookup).
  2. For each number n in the set: if n-1 is NOT in the set → n is a sequence start.
  3. Count upwards from the start: n+1, n+2… until the sequence breaks.
  4. Track the max streak seen.

Step-by-step: nums = [100, 4, 200, 1, 3, 2]

set = {1, 2, 3, 4, 100, 200}
2
Check n=100: is 99 in set? No → sequence start. Count: 100, (101? No) → streak=1.
longest = 1
3
Check n=4: is 3 in set? Yes → NOT a start. Skip.
longest = 1 (unchanged)
4
Check n=200: is 199 in set? No → sequence start. Count: 200, (201? No) → streak=1.
longest = 1
5
Check n=1: is 0 in set? No → sequence start! Count: 1→2→3→4, (5? No) → streak=4.
longest = 4 ✅
6
n=2, n=3 have predecessors in set → not starts. Return longest.
Answer = 4
def longestConsecutive(nums: list[int]) -> int:
    num_set = set(nums)   # O(n) build
    longest = 0

    for n in num_set:
        # Only start counting from sequence beginnings
        if n - 1 not in num_set:
            current = n
            streak = 1

            while current + 1 in num_set:
                current += 1
                streak += 1

            longest = max(longest, streak)

    return longest

func longestConsecutive(nums []int) int {
    set := make(map[int]bool)
    for _, n := range nums {
        set[n] = true
    }

    longest := 0
    for n := range set {
        if !set[n-1] { // sequence start
            curr, streak := n, 1
            for set[curr+1] {
                curr++
                streak++
            }
            if streak > longest {
                longest = streak
            }
        }
    }
    return longest
}
Why is this truly O(n)?

The outer loop runs O(n) iterations. The inner while loop over a sequence of length L runs L iterations. Crucially, these inner loops are NOT nested per iteration — combined across ALL outer iterations, they run at most n total steps (each number is counted once). Total: O(n + n) = O(n).

  2. Brute → Better → Optimal: Mention brute force (O(n²) with set, O(n³) without), then sort approach, then explain the Hash Set insight. Don't jump straight to optimal — show your thought process.
  3. State the key insight clearly: "We only start counting from the beginning of a sequence — when n-1 doesn't exist in the set." This is what interviewers want to hear.
  4. Complexity analysis must explain WHY it's O(n): Many candidates say O(n) but can't justify it. Use the amortized argument — each element is processed at most once by the inner while loop across ALL outer iterations.
  5. Common follow-up: "What if the input is a stream?" → Can't use the same approach; need a Union-Find or sorted structure.

Approach 2 — Hash Map — One Pass Optimal

TimeO(n)
SpaceO(n)

Iterate through the array. For each element, compute its complement (target - num). If the complement is already in the hash map, return the two indices. Otherwise store num:index in the map.

def twoSum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
public int[] twoSum(int[] nums, int target) {
    Map<Integer,Integer> seen = new HashMap<>();
    for (int i = 0; i < nums.length; i++) {
        int complement = target - nums[i];
        if (seen.containsKey(complement))
            return new int[]{seen.get(complement), i};
        seen.put(nums[i], i);
    }
    return new int[]{};
}

Approach 2 — Sliding Window Optimal

TimeO(n)
SpaceO(min(m,n))

Maintain a window [left, right] with a set of characters. Expand right, adding each character. When a duplicate is found, shrink from the left until the duplicate is removed. Track max window size.

def lengthOfLongestSubstring(s):
    char_set = set()
    left = 0
    max_len = 0
    for right in range(len(s)):
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1
        char_set.add(s[right])
        max_len = max(max_len, right - left + 1)
    return max_len

def longestPalindrome(s):
    res = ""
    for i in range(len(s)):
        # Odd length
        l, r = i, i
        while l >= 0 and r < len(s) and s[l] == s[r]:
            if r - l + 1 > len(res):
                res = s[l:r+1]
            l -= 1; r += 1
        # Even length
        l, r = i, i + 1

            if r - l + 1 > len(res):
                res = s[l:r+1]
            l -= 1; r += 1
    return res

Approach 2 — BFS with Queue and Visited Map Optimal

TimeO(V+E)
SpaceO(V+E)

Use a queue for Breadth-First Search and a hash map (clones) to handle cycles. For each node popped from the queue, iterate its neighbors. If a neighbor isn't cloned yet, clone it, add to map, and push to queue. Finally, link the current clone to the neighbor clone.

from collections import deque
from typing import Optional

class Node:
    def __init__(self, val = 0, neighbors = None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []

class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        
        # Edge case: if input graph is empty
        if not node:
            return None
        
        # Dictionary to map original node -> cloned node
        # This acts as:
        # 1. Visited set (prevents cycles)
        # 2. Storage of cloned nodes
        cloned_nodes = {node: Node(node.val)}
        
        # BFS queue initialized with the starting node (original graph node)
        queue = deque([node])
        
        # Standard BFS traversal
        while queue:
             
            # Pop the next node from queue (original graph node)
            current_node = queue.popleft()
            
            # Iterate through its neighbors in the original graph
            for neighbor in current_node.neighbors:
                
                # If this neighbor has not been cloned yet
                if neighbor not in cloned_nodes:
                    
                    # Create clone of neighbor
                    cloned_nodes[neighbor] = Node(neighbor.val)
                    
                    # Add original neighbor to queue for further traversal
                    queue.append(neighbor)
                
                # Connect cloned current node to cloned neighbor
                # cloned_nodes[current_node]  -> cloned version of current node
                # cloned_nodes[neighbor]      -> cloned version of neighbor
                cloned_nodes[current_node].neighbors.append(cloned_nodes[neighbor])
        
        # Return cloned version of the starting node
        return cloned_nodes[node]

Approach 2 — Union Find Optimal

Two conditions must be true for a valid tree: (1) exactly n-1 edges, (2) no cycle. Use Union-Find: for each edge, if both endpoints already share a root, a cycle exists. Afterwards verify all nodes are connected by checking a single root.

def validTree(n, edges):
    if len(edges) != n - 1:
        return False
    parent = list(range(n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    for u, v in edges:
        pu, pv = find(u), find(v)
        if pu == pv:
            return False
        parent[pu] = pv
    return True

        for ch in w:

Approach 1 — DFS Post-Order with Global Max Optimal

TimeO(n)
SpaceO(n)

For each node, compute the max one-sided gain from left and right children (use 0 if negative). The path through this node = node.val + left_gain + right_gain. Update global max. Return to parent: node.val + max(left_gain, right_gain) — only one side can extend to the parent.

def maxPathSum(root):
    global_max = float('-inf')

    def dfs(node):
        nonlocal global_max
        if not node:
            return 0
        left = max(0, dfs(node.left))
        right = max(0, dfs(node.right))
        # Path through current node
        global_max = max(global_max, node.val + left + right)
        # Return max one-sided gain to parent
        return node.val + max(left, right)

    dfs(root)
    return global_max

def isPalindrome(s):
    left, right = 0, len(s) - 1
    while left < right:
        while left < right and not s[left].isalnum():
            left += 1
        while left < right and not s[right].isalnum():
            right -= 1
        if s[left].lower() != s[right].lower():
            return False
        left += 1
        right -= 1
    return True
